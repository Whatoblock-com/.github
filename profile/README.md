Whatoblock runs a network of **HoneyBot** sensors that record unsolicited connections and classify every
source IP as a **scanner, botnet C2, abusive proxy or DDoS source**. That data becomes firewall-ready
blocklists you can drop into firewalls, SIEMs and scripts.

### What you get

| | |
|---|---|
| 🧱 **Blocklists** | Botnet C2, scanners and abusive proxies, filterable by category and confidence. TXT, CSV, JSON and firewall formats |
| 🔎 **Scanner Recon** | TCP/UDP scanners by port, protocol, ASN and country |
| 🤖 **Botnet C2** | C2 server IPs with related malware samples |
| 🌐 **Heartbeat** | Open proxy, Tor exit, datacenter and DDoS IPs |
| 📦 **Open Data** | DNS / NTP / SSDP datasets with bulk downloads |

### Use it

1. Create a free account at **[whatoblock.com](https://whatoblock.com)**
2. Copy your blocklist feed URL
3. Point your firewall, SIEM or cron job at it, and it stays current automatically
